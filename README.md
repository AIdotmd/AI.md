# AI.md

In the 21st century, AI is everywhere. It's being used in smartphones, games and probably toasters too.
But the most common usage of AI is in code.

Now, alot of projects here on github use AI, wether that's fixing bugs, or vibe-coding a website.
Regardless of your stance on AI in FOSS or jus software in general, I think we can all agree that transparency is needed.

That's why i'm calling for developers to start using AI.md.

<br>


## What is AI.md?

AI.md is just a markdown file containing specifications about the usage of AI during development and wether usage of AI is allowed
during contribution. It also must spe cify **how** AI is allowed to be used.

## Symbol table.

AI.md provides special symbols for specifying how AI is allowed to be used 
during contribution (So they are not for explaining how you used AI!)

| Symbol    | Meaning |
| -------- | ------- |
| *        | You can use AI freely.    |
| /        | No AI allowed.     |
| M!    | Mark that your code is AI-assisted in your git commit.    |
| MC!   | Mark in your code where AI was used.
<br>

> Note that the symbol table is just to make it easier, if you wish to explain in plaintext, do that.

You also dont need to limit yourself, if you wish to go very indepth, go right ahead!
Though, AI.md files **are required to have the two base explanation!**

## Extra rule (important!)

You must provide plaintext explanation of the symbols's meaning(s) and optional
extra details about AI if wanted.

You must also provide details about how AI is allowed to be used, and if you used AI in the
first version of the project.
